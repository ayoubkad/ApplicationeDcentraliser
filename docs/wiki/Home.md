# Library DApp Wiki

Welcome to the comprehensive documentation for the **Decentralized Library Application (Library DApp)** - a blockchain-based library management system built on Ethereum, IPFS, and React.

![Library DApp Logo](https://via.placeholder.com/400x200?text=Library+DApp+Wiki)

## 📚 What is Library DApp?

Library DApp is a decentralized application that revolutionizes library management by leveraging blockchain technology. It provides a transparent, secure, and decentralized solution for managing books, users, and borrowing operations in educational institutions.

### 🔑 Key Features

- **Decentralized User Management**: Register and manage users with different roles (Student, Professor, Admin)
- **Smart Book Catalog**: Add, browse, and manage books with IPFS-based cover storage
- **Transparent Borrowing System**: Track borrowing and returns with immutable blockchain records
- **Reputation System**: Incentivize timely returns and maintain user accountability
- **Multi-role Access Control**: Different permissions for students, professors, and administrators
- **IPFS Integration**: Decentralized storage for book covers and metadata

- **Web3**: Web3.js for blockchain interaction
- **Development**: Truffle, Ganache, MetaMask
