Welcome to Library DApp! This quick start guide will get you up and running with the decentralized library system in just a few minutes.

**What you'll need**: Web browser, 5 minutes to set up MetaMask  
**What you'll learn**: How to connect, register, and start using the library

## 🚀 Step-by-Step Setup

### Step 1: Install MetaMask (5 minutes)

MetaMask is your digital wallet and identity for the blockchain.

1. **Visit MetaMask Website**
   - Go to [metamask.io](https://metamask.io)
   - Click "Download"
   - Select your browser

2. **Install Extension**
   - Click "Add to [Browser]"
   - Confirm installation
   - Pin MetaMask to your toolbar

3. **Create Wallet**
   - Click "Get Started"
   - Choose "Create a Wallet"
   - Set a strong password
   - **Save your 12-word recovery phrase safely!**

> 📖 **Need detailed help?** See our [MetaMask Setup Guide](MetaMask-Setup.md)

### Step 2: Configure Network (2 minutes)

Connect MetaMask to the Library DApp network.

1. **Add Network**
   - Click MetaMask network dropdown
   - Select "Add Network"

2. **Enter Network Details**
   
   **For Local Development:**
   ```
   Network Name: Ganache Local
   RPC URL: http://127.0.0.1:7545
   Chain ID: 1337
   Currency Symbol: ETH
   ```
   
   **For Testnet:**
   ```
   Network Name: Sepolia Testnet
   RPC URL: https://sepolia.infura.io/v3/YOUR_KEY
   Chain ID: 11155111
   Currency Symbol: ETH
   ```

3. **Get Test ETH**
   - Visit a Sepolia faucet (for testnet)
   - Request test ETH (it's free!)
   - Wait for confirmation

### Step 3: Connect to Library DApp (1 minute)

1. **Open Library DApp**
   - Navigate to the application URL
   - Wait for page to load completely

2. **Connect Wallet**
   - Click "Connect Wallet" button
   - Select MetaMask
   - Approve the connection

3. **Verify Connection**
   - Check that your wallet address appears
   - Network should show as connected

### Step 4: Register Your Account (2 minutes)

1. **Start Registration**
   - Click "Register" or "Get Started"
   - Choose your role:
     - **Student**: Standard library access
     - **Professor**: Extended borrowing privileges

2. **Complete Registration**
   - Enter your full name
   - Confirm your role selection
   - Click "Register"

3. **Confirm Transaction**
   - MetaMask will open
   - Review transaction details
   - Click "Confirm" (small gas fee applies)
   - Wait for blockchain confirmation

### Step 5: Start Using the Library! (Ongoing)

🎉 **Congratulations!** You're now ready to use Library DApp.

## 🆘 Quick Help

### Common First-Time Issues

**"Can't connect wallet"**
- Ensure MetaMask is unlocked
- Check you're on the correct network
- Refresh the page and try again

**"Registration fails"**
- Check you have ETH for gas fees
- Verify network connection
- Try increasing gas limit

**"Books don't load"**
- Wait for page to fully load
- Check browser console for errors
- Try refreshing the page

**"Images don't appear"**
- IPFS images can take 10-30 seconds to load
- Try refreshing after waiting
- Check internet connection
